# Emotion Detector

An AI-based web application that analyzes text and detects emotions using Watson NLP.

## Final Project Tasks

This repository contains the work for the Emotion Detector final project, including:

- Emotion detection with Watson NLP
- Formatted emotion output
- Python package structure
- Unit testing
- Flask web deployment
- Error handling
- Static code analysis

## Main Components

- `EmotionDetection/emotion_detection.py` — emotion detection logic
- `EmotionDetection/__init__.py` — package initialization
- `test_emotion_detection.py` — unit tests
- `server.py` — Flask web application
