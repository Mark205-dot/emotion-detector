# Final Project: Emotion Detector

This is the **Final Project** for the AI-based Emotion Detector application.

The application analyzes text and detects the emotions anger, disgust, fear, joy, and sadness using the Watson NLP Emotion Predict service. It also identifies the dominant emotion and exposes the functionality through a Flask web application.

## Project Name

**Emotion Detector**

## Final Project Tasks

- Watson NLP emotion detection
- Formatted emotion output
- Python package structure
- Unit testing
- Flask web deployment
- Error handling
- Static code analysis

## Main Components

- `emotion_detection.py` — Task 2 root-level application function
- `EmotionDetection/emotion_detection.py` — packaged final emotion detection logic
- `EmotionDetection/__init__.py` — package initialization
- `test_emotion_detection.py` — unit tests
- `server.py` — Flask web application
